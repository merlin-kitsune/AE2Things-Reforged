[h1=AE2 Things Reforged 更新日志]

AE2 Things Reforged 是 AE2 Things 的优化分支：完整保留原模组的全部功能（DISK 磁盘、驱动器、分区、模糊卡 / 反向卡、/ae2things 命令），同时大幅削减大网络下由该模组带来的额外开销，并修掉了一批会造成数据丢失或存档损坏的问题。

本模组按 Minecraft 版本分两条线并行发布，版本号各自独立：

  • Minecraft 1.21.1 / NeoForge：当前版本 1.4.5，需要 NeoForge 21.1.248+ 与 AE2 19.2.18 – 19.x，Java 21；
  • Minecraft 1.20.1 / Forge：当前版本 1.3.1，需要 Forge 47.1.47+ 与 AE2 15.4.12 – 15.x，Java 17。

两条线的 modId 都是 ae2things，方块 / 物品 id 与存档格式都与各自 Minecraft 版本的上游发布版一致，因此是直接替换：旧存档与旧磁盘照常可用，但不能与原 AE2 Things 同时安装。

[h2=Minecraft 1.21.1 / NeoForge 线] [h3=1.4.5（2026-11-05）]

需 NeoForge 21.1.248+ 与 AE2 19.2.18 – 19.x，Java 21。

修复

  • 两块元件可能共用一个磁盘条目：/ae2things recover <uuid> 现在改为铸造新 id 并复制内容（与创造模式中键克隆一致），不再给出第二个指向同一 id 的物品。此前两个 inventory 写同一条目、后写者覆盖，且清空其中一块会连带删掉另一块仍在使用的条目。
  • 读不出来的磁盘条目会被永久抹掉：id 缺失或格式错误、内容无法解码的条目，现在一律原样保留并在下次保存时写回；单个坏条目也不会再连带清空整张侧表。
  • 只探测容量的元件也会写数据：SIMULATE 插入不再铸造磁盘 id、不再写入物品总数，管道 / 输入策略 / 客户端预测探测元件时不会再标脏存档或留下游离条目。
  • 拆解磁盘时一并移除它的侧表条目，空条目不再堆积。
  • 服务端侧表不可用时，写入由「静默丢失」改为直接拒绝。

优化

  • 读磁盘变成真正的只读：显示或扫描磁盘不再创建侧表条目、不再标脏存档。
  • 加载侧表不再标脏，世界加载后的第一次自动保存不会重写整张表。
  • 物品染色与 tooltip 直接从物品堆读取，不再每帧构造一次 cell inventory。
  • 克隆磁盘时深拷贝序列化后的 key tag，不再与新条目共用实例。
  • mixin 配置改为 required：注入失败直接启动失败，而不是静默禁用中键克隆保护。

兼容

  • AE2 MEGA Things 2.0.4：它引用的 17 个符号全部存在，注入的三个位置依然匹配（已对构建产物逐条核对）。
[h3=1.4.3（2026-10-06，本分支首个发布版）]

性能

  • 落盘时复用每块磁盘已序列化的 key tag 并原地更新数量，不再每次保存都重新编码全部 key；缓存索引失效时回退到完整重建。
  • 物品总数改为增量维护（O(1)），不再每次变更都对整个 key 集合求和。
  • 同机实测：32 key 的磁盘做 500 次纯数量保存 1 ms（上游 9 ms）；2000 次零值提取 0 ms（上游 81 ms）。

修复

  • 克隆 DISK 不再让两块磁盘共用同一个 DataStorage 实例（此前任意一块都能覆盖另一块的内容）。
  • 数量数组与 key 数组长度不一致的元件不再越界索引，也不会被静默截断。
  • IDISKCellItem.isBlackListed() 不再假设 key 一定是物品，并对其查询的 cell inventory 做空判断。
  • DISK tooltip 与「Disk UUID」一行改为翻译键，五个语言文件的键集完全一致。

说明

  • 与上游 1.4.2 做了逐字节对比（9 组黄金样本、108 个 key），落盘格式完全一致，替换 jar 后旧磁盘照常可读。
[h2=Minecraft 1.20.1 / Forge 线] [h3=1.3.1（2026-11-05，首次发布）]

需 Forge 47.1.47+ 与 AE2 15.4.12 – 15.x，Java 17。这是把 1.21.1 的完整功能集移植到 1.20.1，包含本分支的全部性能优化与缺陷修复；GUI 仍使用 1.20.1 的经典素材（AE2 在 1.21.1 重绘了全部界面素材，只有老素材才与 1.20.1 的 AE2 匹配）。

内容

  • 1k / 4k / 16k / 64k / 256k DISK 元件，无类型上限，一个物品占一字节；含磁盘外壳与驱动器配方。
  • 分区、模糊卡、反向卡；支持 ME 驱动器与 ME 箱子。
  • /ae2things help、/ae2things getuuid、/ae2things recover <uuid> [DISK]。
  • 恢复了 ME 箱子元件处理器：右键放有 DISK 的 ME 箱子直接打开 ME 存储界面（与上游 1.2.1 一致）。

性能：序列化结果按键缓存、纯数量变化原地更新、物品总数增量维护、读路径只读、加载不标脏、渲染不再每帧构造 inventory。

修复：中键克隆改为复制内容（不再共用条目）、/ae2things recover 铸造新 id 并复制、无法读取的侧表条目原样保留、SIMULATE 不再写数据、拆盘清理侧表、长度不一致不再崩溃、服务端表不可用时拒绝写入。

兼容

  • AE2 MEGA Things 1.0.8：在装有该模组的真实 Forge 1.20.1 服务端上验证——它的两个 mixin 均生效，/ae2things 帮助文本按预期被改写。
[h2=版本号说明]

两条线各有两个版本号只存在于构建与测试阶段、并未对外发布（1.21.1 的 1.4.4、1.20.1 的 1.3.0）：它们的内容一字未改地并入了随后的 1.4.5 / 1.3.1，版本号顺延只是因为发布 tag 已被占用。因此下载页面上不会出现这两个版本，也无需寻找。
